# Tools

Command-line entry points for verified extraction, focused research validation,
exports, and the JFG Forge desktop application live here. Extractors take
explicit read-only inputs and write only to a new output directory.

Run `python -B tools/<tool>.py --help` for the arguments of a non-GUI tool. The
Forge launcher is `python -B tools/run_jfg_forge.py` after installing the
dependencies declared in `pyproject.toml`.
