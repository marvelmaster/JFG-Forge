# Vela research

This directory records the character-specific investigation of Vela. Boy/Juno
remains the frozen comparison baseline. The established Phase-1/Phase-2 model,
animation, and GirlGun results now back the experimental Vela MVP in JFG Forge.
An independent live 28-matrix Vela capture remains pending.

- [`phase1-discovery.md`](phase1-discovery.md): identity, static model layout,
  textures, transform hierarchy, reference points, and immediate child objects.
- [`phase1-structural-map.json`](phase1-structural-map.json): machine-readable
  evidence generated by `analyze_vela_phase1.py`.
- [`phase2-animation-runtime.md`](phase2-animation-runtime.md): Vela's 53-entry
  animation source, isolated 28-transform reference pose, generic Girl runtime
  calls, verified `0x400` path, and verified GirlGun matrix-6 socket.
- [`phase2-runtime-map.json`](phase2-runtime-map.json): reproducible Phase-2
  catalog, pose, instruction, geometry, attachment, and capture evidence,
  generated by `analyze_vela_phase2.py`.
- [`runtime-timing.md`](runtime-timing.md): independently derived 53-entry
  Girl overlay timing catalogue, movement/state dependencies, rates, and the
  shared Forge preview/export interpretation.
- [`runtime-timing-map.json`](runtime-timing-map.json): machine-readable timing
  evidence generated from the pinned ROM by `analyze_vela_runtime_timing.py`.

Phase 2 provides the decoder and static runtime-path validation. Forge now
integrates that Vela model/animation path and the independently VERIFIED Game
Timing catalogue. Exact numerical pose correlation against one live Vela
28-matrix capture remains future work.
